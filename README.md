# Лето 2026

Одностраничный сайт-дневник о лете 2026 года: блок «обо мне», две истории, слайдер с фото, цитата сезона и переключатель светлой/тёмной темы.
ссылка на фигму: https://www.figma.com/design/gIE7uFGdkDCMVcHkzNqZjp/Untitled?node-id=0-1&t=4JVTsbfBdNCQyb63-1

## Структура проекта

```
├── index.html      — разметка страницы
├── style.css        — все стили (один файл, без препроцессоров)
├── script.js        — логика слайдера и переключения темы
├── img/              — изображения (фото, смайлы в футере, пальмы для фона)
└── video/            — видео для главного блока (hero)
```

## Методология

Вёрстка сделана по **БЭМ**: `блок__элемент`, модификаторы через `--` (например, `.page--dark`). Инлайн-стилей и `!important` нет, все размеры — в пикселях.

Основные блоки: `header`, `about`, `osn`, `story`, `card`, `story-secondary`, `slider`, `quote`, `footer`.

## Что нужно подключить самому

| Что | Куда положить | Как называется в коде |
|---------------|--------------|---------------------------------------------------------|
| Главное видео | `video/hero.mp4` | `<video class="osn__video" src="./video/hero.mp4">` |
| Фото «Озеро» (карточка 1) | `img/photo_2026-09-03_17-08-42.jpg` | `.card__image img` |
| Фото «Ремонт» (карточка 2) | `img/remont.jpg` | `.card__image img` |
| Фото «Стрит» (карточка 3) | `img/стрит.jpg` | `.card__image img` |
| Фото истории 2 (Алтай) | `img/алтай_основа.jpg` | `.story-secondary__image` |
| Фото слайдера | `img/сл1.jpg`, `img/сл2.jpg`, `img/слайд3.jpg` | `.slider__item` |
| Фото к цитате | `img/citate.jpg` | `.quote__image img` |
| Смайлы в футере | `img/smile1.png`, `img/smile2.png` | `.footer__emoji` |
| Фон-пальмы | `img/palms.png` | фон `<body>` |

Имена файлов можно поменять — просто отредактируй соответствующий `src` в `index.html`.

## Функциональность (script.js)

Слайдер — стрелки `‹ ›` и номер переключают слайды (показывается один активный, остальные скрыты через класс `.slider__item--active`).
Тема — кнопка «Тема» в шапке добавляет/убирает класс `.page--dark` на `<body>`. Выбор темы запоминается в `localStorage`, при следующем визите применяется автоматически.

## Адаптивность

Брейкпоинт `768px`: шапка, карточки, история 2 и футер переключаются в колоночную раскладку, фон с пальмами перестаёт быть `fixed` (на мобильных это тормозит).

## Как открыть

Просто открой `index.html` в браузере — сборка не нужна, зависимостей нет.
